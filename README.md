# Prem Patel — React Portfolio

A responsive personal portfolio inspired by the neo-brutalist style of the referenced Dhruv Patel portfolio.

## Included
- React + Vite
- Responsive mobile navigation
- Dark/light theme
- About section
- Skills section
- Projects section
- Journey timeline
- Contact form UI
- GitHub / LinkedIn / email buttons
- No backend required

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Customize

Edit `src/main.jsx` to change:
- name
- email
- social links
- skills
- projects
- journey

Edit `src/index.css` to change colors and design.

## Important

Replace `your-email@example.com` and the placeholder GitHub/LinkedIn links with your real accounts before publishing.
